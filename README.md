# Nova AI — Landing Page Concept

Навчальна концепція оновленого сайту для AI-креатор агентства (практичне ТЗ), натхненна референсом nashe.agency (тільки рівень подачі, без копіювання).

## Стек і інструменти

- Vanilla HTML5 / CSS3 / JavaScript (ES modules), без білд-кроку
- Node.js built-in test runner (`node --test`) для unit-тестів логіки (i18n, валідація форми, умова показу інтро)
- Google Fonts: Space Grotesk, Inter
- Claude (Anthropic) — асистент для брейнштормінгу концепції, дизайну та написання коду

## Запуск локально

Сайт використовує ES-модулі (`<script type="module">`), тому відкрити `index.html` подвійним кліком не вийде — браузери блокують модулі на `file://`. Потрібен будь-який локальний статичний сервер, наприклад:

```bash
python -m http.server 5173
```

і відкрити `http://localhost:5173`. Build-кроку не потрібно.

## Тести

```bash
npm test
```

## Відомі обмеження

- Форма заявки — тільки UI-демонстрація: валідує поля й показує повідомлення про успіх, але нікуди реально не відправляє дані (свідоме рішення для навчального концепту, не баг).
- Приклади робіт у портфоліо — процедурні CSS/SVG-візуали, а не реальні клієнтські кейси.
