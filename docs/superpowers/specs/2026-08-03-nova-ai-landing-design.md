# Nova AI — Landing Page Design

## Контекст

Навчальне практичне ТЗ: підготувати концепцію оновленого сайту для "AI-креатор агентства" за референсом nashe.agency (тільки рівень подачі/структури, не копіювання). Реальних даних замовника (назва, послуги, кейси, відгуки) немає — працюємо з вигаданим брендом-заглушкою, чітко придатним для конкурсу (без фейкових відгуків/цін/цифр).

Ціль: зробити не просто макет, а живий закодований сайт (виграшніше за Figma-макет інших учасників), задеплоєний на Vercel.

## Бренд

- **Назва:** Nova AI
- **Заголовок hero:** "Твоя ідея заслуговує вибухового старту"
- **Підрядок hero:** "Ми запускаємо її в реальність за допомогою AI"
- **Ніша:** AI-креатор агентство (генерація візуалів, відео, контенту, автоматизація на базі AI)
- **Тон:** преміальний, статусний, технологічний, "неземний"/космічний

## Стек

- Vanilla HTML/CSS/JS, без білд-кроку
- Один файл `index.html` + `styles.css` + `main.js` (+ `i18n.js` для перемикання мов)
- Деплой: код у публічному GitHub-репозиторії, підключеному до Vercel через "Import from GitHub" (автодеплой при кожному пуші). Користувач сам авторизується в GitHub/Vercel — створення акаунтів не автоматизується. Структура лишається сумісною з будь-яким статичним хостингом.
- Мова: білінгва UA/EN через перемикач (дані рядків через `data-i18n` атрибути + JSON-словник, без переходу на окремі URL)

## Візуальна система

### Кольори (CSS custom properties)

```
--bg-deep: #020409
--bg-mid: #071224
--bg-radial: radial-gradient(ellipse at 50% 25%, #0a1b30 0%, #030710 60%, #000103 100%)
--accent-blue: #5fc4ff
--accent-blue-2: #3f8fe0
--accent-violet: #b98cff   /* акцент у голографічній рамці кнопки */
--accent-teal: #7fe0d0     /* акцент у голографічній рамці кнопки */
--text-primary: #eaf6ff
--text-secondary: #9fc7e6
--text-muted: #6a86a0
--glass-bg: rgba(255,255,255,.05)
--border-glass: rgba(255,255,255,.16)
```

Фон: глибокий космічний градієнт + 3 шари зірок (CSS radial-gradient, різні розміри/opacity) + м'яка туманність (blur radial-gradient), без "flat" чорного фону.

### Типографіка

- Заголовки: **Space Grotesk** (Google Fonts) — геометричний, технологічний
- Основний текст: **Inter** (Google Fonts) — читабельний, нейтральний
- Підключення через `<link>` до Google Fonts (сайт онлайн, це стандартна практика)

### Кнопки (сигнатурний стиль, затверджено користувачем)

- **Primary:** glass-фон + анімована обертова "голографічна" conic-gradient рамка (blue → violet → teal) + shimmer-скіп, hover — підйом і посилення сяйва
- **Secondary:** тиха ghost-кнопка, напівпрозоре скло, тонка біла межа
- **Chip (на картці послуги):** маленька кнопка "Обрати послугу →", синє світіння при hover

## Структура сторінки

1. **Intro-анімація** (тільки при першому візиті за сесію, `sessionStorage`)
   - Canvas-частинки: два кластери зліва/справа "розходяться шторками" (~2.5с, easing)
   - У центрі проявляється лого "Nova AI" (fade+scale, glow); підрядка/заголовка в інтро немає — вони з'являються вже на hero
   - Overlay фейдиться (~0.5с), під ним вже готова головна сторінка
   - Кнопки CTA в інтро немає — тільки лого + таглайн
   - Маленька непомітна кнопка "Пропустити" в кутку (accessibility/повторні відвідувачі, що потрапили за прямим лінком)
   - `prefers-reduced-motion: reduce` → інтро пропускається одразу, без анімації

2. **Hero (головний екран)**
   - Той самий космічний фон (без інтро-оверлею), лого/назва, заголовок "Твоя ідея заслуговує вибухового старту", підрядок "Ми запускаємо її в реальність за допомогою AI", короткий опис на 1-2 речення, Primary CTA "Залишити заявку" + Secondary "Дізнатись більше" (скрол вниз)

3. **Про агентство** — короткий блок 2-3 речення, що таке Nova AI і чим відрізняється

4. **Послуги** (6 карток, сітка 3x2 / 1 колонка на мобільному):
   1. AI-генерація візуалів та брендинг
   2. AI-відео та моушн-дизайн
   3. AI-контент для соцмереж
   4. AI-автоматизація та боти
   5. AI-копірайтинг
   6. Консалтинг з впровадження AI
   
   Кожна картка: іконка (inline SVG), назва, короткий чіпляючий підзаголовок (за прикладом референсу), кнопка-чіп "Обрати послугу →" → скрол до форми + автовідмітка чекбокса цієї послуги

5. **Приклади робіт / портфоліо**
   - Сітка карток з процедурними AI-стиль візуалами (CSS/SVG градієнтні абстрактні композиції, генеровані кодом — без зовнішніх зображень і без вигаданих клієнтських кейсів)
   - Підпис під кожною: тип роботи ("AI-візуал", "Приклад моушн-кадру" тощо), позначено як навчальний приклад

6. **Процес співпраці** (5 кроків, горизонтальний таймлайн / вертикальний на мобільному):
   1. Заявка та брифінг
   2. Концепція та стратегія
   3. Генерація та розробка
   4. Узгодження та доопрацювання
   5. Запуск та підтримка

7. **Переваги агентства** (4-6 пунктів з іконками): швидкість завдяки AI, індивідуальний підхід, мультидисциплінарність в одному місці, прозорість процесу, сучасні AI-інструменти

8. **Контакти / форма заявки**
   - Поля: ім'я, email/телефон, повідомлення
   - Мультивибір чекбоксів "Що вас цікавить?" (6 послуг, синхронізовано з кнопками-чіпами вище)
   - Валідація на клієнті, кнопка Primary "Відправити"
   - **UI-only:** без реального бекенду — після валідації показується inline-повідомлення "Дякуємо! Ми зв'яжемось з вами найближчим часом" (без фактичної відправки даних кудись)
   - Іконки месенджерів (Telegram/WhatsApp) як декоративні елементи дизайну, без реальних посилань (немає справжніх акаунтів агентства)

9. **Футер**: лого, коротке гасло, копірайт-рядок

## Мовний перемикач

Кнопка UA/EN у хедері (фіксований header з'являється після скролу вниз через hero). Перемикання без перезавантаження — JS міняє `textContent` елементів з `data-i18n` за словником у `i18n.js`.

## Адаптивність

- Mobile-first підхід, breakpoints: ~480px, ~768px, ~1024px
- Картки послуг/портфоліо/переваг: grid → одна колонка на мобільному
- Процес співпраці: горизонтальний таймлайн → вертикальний список на мобільному
- Інтро-анімація спрощується на мобільному (менше частинок, коротша тривалість) для продуктивності

## Поза межами обсягу

- Реальна відправка форми на email/CRM
- Окремі підсторінки (сайт — один лендинг, як і вимагає ТЗ)
- Реальні відгуки клієнтів, ціни, статистика (заборонено умовами ТЗ)
- Багатомовність окремими URL (тільки клієнтський перемикач)

## Перевірка перед здачею

- Відкрити в браузері (desktop + mobile viewport), пройти інтро → hero → усі секції → форму
- Перевірити перемикач мов на всіх секціях
- Перевірити `prefers-reduced-motion`
- Задеплоїти на Vercel і перевірити публічне посилання
